# 🏏 Cricket Scorecard Web App

A modern, responsive Cricket Scorecard web application built using **HTML, CSS, and JavaScript**.
This app allows users to score a cricket match ball-by-ball with live updates, sound effects, milestone notifications, and local storage support.
---
## 🚀 Features

✅ Ball-by-ball scoring (0,1,2,3,4,6)  
✅ Wide & Wicket tracking  
✅ Automatic over count (6 balls = 1 over)  
✅ Ball history display  
✅ 50 Up & 100 Up milestone notifications  
✅ Hat-trick detection  
✅ Sound effects (Wicket, Boundary, Hat-trick, 50, 100)  
✅ 5-second animated toast notifications  
✅ LocalStorage support (data saved on refresh)  
✅ Undo last ball  
✅ Reset match  
✅ Fully responsive (Mobile + Desktop)  
✅ Modern glassmorphism UI design  
---
